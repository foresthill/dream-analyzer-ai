# シンボル辞典の使い方

アプリは、キュレーションした**シンボル辞典**（`SYMBOL_DATABASE`）を持っている。各エントリは:

- `symbol`（例: 水）
- `category`（nature / actions / places …）
- `interpretations`: general / positive / negative / cultural
- `relatedSymbols`（例: 海・川・雨・涙）← これが庭のリンク構造になる
- `keywords`

## 2つの使われ方
1. **AI分析の“参考情報”として注入**: 夢のテキストに関連する項目だけを抜き出し、プロンプトに添える。当てはまらなければ使わない、という但し書き付き。
   → [[夢分析プロンプトの設計]]
2. **読み物としての辞典**: アプリ内のシンボル辞典ページで、意味やカテゴリを探索。

## garden的な価値
`relatedSymbols` は、そのまま **ノート間リンク**になる。「水 → 海・川・涙」と辿れることで、断片が繋がり、[[繰り返しパターンから読む|繰り返し]]と合わせて全体像が育つ。

> [!tip] 拡張案
> 辞典をAIにそのまま“解説させる”のではなく、ユーザー自身の夢での用例（バックリンク）を一緒に見せると、一般的意味と個人的意味が並んで学べる。
