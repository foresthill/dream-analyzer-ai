# 夢シンボルの読み方

シンボルには**普遍的な意味**と**個人的な意味**の両方がある。辞書的な意味から入りつつ、最後はその人の文脈に落とす。

## カテゴリ別の手がかり
- **人物 (people)**: 自己の側面 / 重要な人間関係 / 内なる声
- **動物 (animals)**: 本能的な側面 / 特定の性質 / 自然との繋がり
- **場所 (places)**: 心理状態 / 人生の段階 / 安全か危険か
- **物体 (objects)**: 道具や資源 / 記憶や連想 / 象徴的な意味
- **行動 (actions)**: 対処の仕方 / 欲求や恐怖 / 変化のプロセス
- **自然 (nature)**: 感情の状態 / 生命力 / 変化と成長

## 解釈の4原則
1. **文脈で読む** — 夢全体の流れの中でシンボルを見る。
2. **個人的な関連を優先** — 一般的意味より、その人の経験。
3. **感情を重視** — シンボルに対する感情的反応が鍵。
4. **複数の解釈を持つ** — 一つに固執しない（肯定・否定の両面）。

## 例（辞典から）
- **水**: 感情・潜在意識・流れ・変化。肯定＝浄化/癒し、否定＝感情の氾濫。関連: 海・川・雨・涙。
- **飛ぶ**: 自由・解放・視点の変化。否定＝現実逃避。
- **追いかけられる**: 逃避・不安・直面すべき問題。
- **歯が抜ける**: 自信の喪失・変化への不安。
