# 過去の夢を文脈に使うRAG

夢分析の「深さ」は、**今回の夢だけでなく過去の履歴を渡す**ことから生まれる。大げさなベクトル検索ではなく、ヒューリスティックな文脈注入でも十分効く。

## 仕組み（ざっくり）
```
新しい夢
  → DBから同じ「夢を見た人」の過去の夢を取得（直近10件）
  → パターン検出：2回以上出たテーマ/シンボルを集計
  → プロンプトに注入：今回の夢 + 最近の履歴 + 繰り返しテーマ/シンボル
  → 「過去との関連・変化にも言及して」と指示
  → 過去を踏まえた深い解釈
```

## 渡すデータ
| データ | 量 | 用途 |
|---|---|---|
| 過去の夢の概要 | 直近10件 | 時系列の文脈把握 |
| 繰り返しテーマ | 2回以上すべて | 「変化への不安」等の傾向 |
| 繰り返しシンボル | 2回以上の上位10 | 「水」「階段」等の傾向 |

分析後の**チャット**でも、直近5件の過去の夢をシステムプロンプトに含め、「前の夢と関連ある？」に答えられるようにしている。

## 設計上の注意
- **必ず `userId` で絞る**。関連（dreamerId）だけで取ると他人のデータが混ざり得る。
  → [[ユーザー横断を防ぐ設計]]
- これは“軽いRAG”。将来は埋め込み検索で「意味的に近い過去の夢」を引くと更に深くできる。
