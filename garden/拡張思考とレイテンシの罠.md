# 拡張思考とレイテンシの罠

## 症状
[[AI分析をストリーミング表示にする]]を入れたのに、**30秒ずっとスピナー → 最後の1秒だけ文字が流れる**。配信形式（NDJSON/SSE）をいくら直しても変わらない。

## 真因
既定モデルを新世代（例: Claude Sonnet 5 / Opus 5）にしたところ、**`thinking` を省略すると“思考モード”が既定でON**になる仕様だった。

- 思考中は **可視テキストのイベントが出ない**（内部で考えているだけ）。
- だから配信形式に関係なく「無音で待たされ、思考が終わってから答えが一気に出る」。
- 症状（最後の数秒だけストリーム）と完全一致。

## さらに：思考はトークンも食う
思考トークンは**出力トークンとして課金**され、しかもこのアプリでは**表示すらしていなかった**。「見えないのにお金だけかかる」状態。
→ ストリーミング自体はトークンを増やさない。増やすのは“思考ON”。

## 対処
- Anthropic 呼び出しで **`thinking: { type: 'disabled' }`** を送る → 最初のトークンから流れる＆コスト減。
- OpenRouter は **`reasoning: { enabled: false }`**（推論モデル向け）。
- **古いモデルが `thinking` を拒否**する場合に備え、まだ何も出力していなければ**パラメータを外して自動再試行**（分析を失敗させない）。

## 教訓
- 新モデルは“賢いが遅い既定”になりがち。**既定のthinking挙動はモデルごとに違う**ので要確認。
- 「速い⇄深い」はトレードオフ。対話的な用途は思考OFFで即応、深掘りは別途ON、と切替可能にするのが理想。
